### 🗂️ Fill Bin System (OOP - Java)

A Java-based application that demonstrates Object-Oriented Programming concepts through a simple “fill bin” logic system. The project models how items are stored, managed, or processed within a container-like structure.

#### 🚀 Features

* Simulates adding/filling items into a bin
* Encapsulated logic using classes
* Clear and modular code structure
* Beginner-friendly implementation of OOP concepts

#### 🛠️ Tech Stack

* **Language:** Java
* **Paradigm:** Object-Oriented Programming (OOP)

#### 📂 Project Structure

* `FillBin/` – Core logic for bin operations
* `Item/Class files` – Represents elements being managed
* `Main.java` – Entry point for execution

#### 🎯 Purpose

This project was developed to:

* Practice OOP concepts in Java
* Understand how to model simple systems using classes
* Improve problem-solving and code organization skills
